# Ecos do Passado: A Mensagem Perdida - Visual Novel

Um jogo de suspense e terror psicológico ambientado em 1984, desenvolvido em formato de Visual Novel interativa.

## 🛠️ Tecnologias Utilizadas
* **HTML5 & Tailwind CSS** (Interface e Estilização)
* **JavaScript (Vanilla)** (Lógica de jogo, inventário e nós narrativos)
* **Web Audio API** (Sintetizador nativo para efeitos sonoros e ambientação)
